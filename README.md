# Appointment Booker

This project is a simple prototype of a appointment booking site for a medical office.
It includes a React front-end and a Express back-end API using SQLite for the server database.

## How to run

The React front-end can be run in dev mode.
Logging in requires the server to be running.

By default the server will run on localhost port 3001.

To start the server, run 'server.js' located in the 'server' folder. using Node.js.
This will automatically create the database and generate a 'database.db' file to store the data.

The server can be shut down using Ctrl + C in the terminal.
